# ADR 0005 — Login required

## Status

Accepted (human-confirmed 2026-08-28).

## Decision

Internal users must sign in before using the app or API.

MVP auth is **environment-backed single-operator credentials**:

- `AUTH_EMAIL`
- `AUTH_PASSWORD`
- `AUTH_SECRET` (≥ 16 chars, HMAC session cookie)

Routes except `/login` and `POST /api/auth/login` require a valid httpOnly session cookie. Logout is `DELETE /api/auth/login`.

No public registration. No OAuth/SSO in this slice. Multi-user identity can replace env credentials later without changing the invoice schema.

## Consequences

- n8n/DevOps must inject auth secrets; they must never be committed.
- Invoice APIs return 401 when unauthenticated.
